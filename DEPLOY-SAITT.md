Эта ветка не опубликована. Основной GitHub Pages и его CNAME в main менять нельзя: старый адрес должен продолжать работать.

Проверено 11 сентября 2026: DNS saitt.ru обслуживает Timeweb; rieltor-maksim.saitt.ru возвращает NXDOMAIN. IP корневого saitt.ru не является подтверждённым адресом хостинга для этой копии.

Для завершения:
1. Определить существующий хостинг сайта жалюзи и создать отдельный сайт для rieltor-maksim.saitt.ru без замены других сайтов.
2. Разместить index.html, family-mortgage/index.html, favicon.svg, hero-apartment.png, maksim-pivovarov.jpeg, og.png. Служебную папку cloudflare публиковать как веб-контент не требуется.
3. Создать DNS-запись к подтверждённому хостингу и выпустить HTTPS-сертификат.
4. Настроить /api/lead на новом хосте. Относительный путь уже используется обеими формами. В копии cloudflare/lead-worker.js добавлен новый HTTPS Origin, старые сохранены. Перед обновлением работающего Worker получить его фактическую текущую версию: код в GitHub может отличаться от исправленной почтовой версии. Применять только добавление Origin, не перезаписывать почтовую интеграцию старым кодом.
5. Проверить маршрутизацию и некорректный POST без отправки письма. Реальное тестовое письмо — только после отдельного разрешения пользователя.
6. Проверить новый и старый адреса обеих страниц, изображения и единственное подключение Метрики.

В cloudflare/wrangler.jsonc остаётся старый маршрут. Новый маршрут нельзя добавлять без подтверждения, что saitt.ru доступен как зона в данном аккаунте Cloudflare; сейчас его NS находятся в Timeweb.
